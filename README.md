# MARS Simulation! 
Made with Godot Engine
Languages: GDScript and Python

[v1 Video Demo](https://youtu.be/4YVjVeLYXBA) - May 10, 2026

## Features
- First person!
- Walk around
- Pick up objects (only a watercan for now)

... Yeah, not a lot for now.
